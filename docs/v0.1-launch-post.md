## Details comment

**Nacre** is a Wayland desktop I've been building and using daily. Pick a wallpaper and the bar,
window frame, launcher, terminal and apps follow it, in dark or light.

- Compositor: [nacre-niri](https://github.com/nacre-desktop/nacre-niri), a fork of niri. Stock niri and Hyprland work too, with fewer features.
- Shell: [Bead](https://github.com/nacre-desktop/bead), a native shell toolkit: Rust for rendering and input, Luau for the UI. Not Quickshell or Waybar.
- Colours: [Orient](https://github.com/nacre-desktop/orient), with templates for GTK, Qt, Kitty, Chromium, Discord and Spotify.
- In the video: <list the shown parts: bar and pearls, launcher, dashboard, control centre, wallpaper picker, detachable panels>.
- Wallpaper: <source and credit>.

**Install** (Arch or CachyOS, x86_64; read the script first):

```sh
sudo pacman -Syu --needed curl gnupg
curl --fail --location https://nacre-desktop.github.io/nacre/install-arch.sh -o /tmp/nacre-install-arch.sh
less /tmp/nacre-install-arch.sh
bash /tmp/nacre-install-arch.sh --plan
bash /tmp/nacre-install-arch.sh
```

Full steps and uninstall: [installation docs](https://github.com/nacre-desktop/nacre/blob/main/docs/installation.md).
Repo and configs: [github.com/nacre-desktop/nacre](https://github.com/nacre-desktop/nacre) (shipped app configs live in `config/`).

**Performance.** The shell was first written in QML, then ported to Bead with the same features.
Measured against the QML original in a nested 1280x720 fixture (median of 3 runs per shell):
about 10x less shell memory (52 vs 511 MiB), 20x lower idle CPU (0.10% vs 2.02% of a core) and
less than half the idle power (+0.65 vs +1.47 W). During interaction, shell plus daemon CPU is
47% against 57%. Method and caveats:
[benchmark report](https://github.com/nacre-desktop/nacre/blob/81211b077/docs/research/bead-vs-qml-shell-benchmark-20261110.md).
