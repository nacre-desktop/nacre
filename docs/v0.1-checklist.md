# v0.1 public preview checklist

v0.1 is the first public preview. You install it from the command line on x86_64
Arch Linux or CachyOS through the signed pacman repository and `install-arch.sh`,
and update it with `pacman -Syu` and `nacre update`. An installer ISO comes later.
Every item below must be done before the preview is announced. Publishing (tags,
releases, the package repository) is approved by the owner each time.

Compositor tiers:

| Tier | Compositor | What works |
| --- | --- | --- |
| 1 | nacre-niri (Nacre's niri fork) | Everything, including collections, panel motion and overview effects |
| 2 | Stock niri, Hyprland | The core shell. Features that need the fork are hidden. |

State key: **todo**, **active**, **done** (on main, CI green), **verified** (passes
the fresh-install VM gate or the owner's live check).
