# N0079 — Launch the existing updater through `tools.launch`

Status: Implemented; pending CI and lead review. The Bead updates dropdown sends `tools.launch {tool:"updates"}`; the N0051 closed tool enum did not accept it. Add `updates` as an additive enum variant and start the existing updater in the same Kitty window used by QML: `kitty --class nacre-control --title "System updates" -- nacre updates`. The `nacre updates` route reaches `nacre/shell-tools/updates.sh`, retaining its existing Qt preflight and confirmation flow. No updater behavior or package command changes.

The helper test substitutes fake `kitty` and `nacre` executables and asserts the exact Kitty argv; it never starts the updater. Bead callers found in B0070 (audio-manager, connection-editor, setup, ai-workspace, aur-review-policy, power-service) match the prior enum. B0112/B0124's new `updates` caller was the only mismatch and is now covered.

Protocol schema, Luau type and transcript fixture are regenerated by `cargo run -p nacre-protocol --example export`. No temporary duplicate introduced. Validation requires the full `desktop` job from `.github/workflows/check.yml` in the Arch CI container on a remote build host.
