# N0219 Launcher keyboard and search UX

The file-search hint uses the reserved results subtitle, keeping the first row stationary. Keyboard arrows move among the category rail, content and quick controls, with Bead's primary focus ring. Rail navigation switches categories live and scrolls the focused entry into view; Right/Enter enters the first item, including after an asynchronous category load. Quick controls retain focus while a toggle is pending. Typing returns to search; Left/Right edit nonempty text, with Left entering the rail at caret position zero. Native Widgets retains its existing handoff.

The bar logo and Super+Space normalize the same empty-query request through one opener: Home with Favorites. Existing menu navigation and control actions are reused; the old arrow interception is removed. Focus and selection share a staged frame, with two transient focus strings and one existing event callback for loading content; no new service or duplicate implementation remains.

Validation in a fresh `n0200-build:latest` container on dev-1: 118 focused launcher tests passed; the complete shell binary passed 892 tests with 4 ignored. Formatting, shell clippy, Luau analysis (189 modules), Ruff 0.16.10 and the compositor boundary check passed. Regression coverage includes first-row pixel coordinates for `""`, `":"` and `":ab"` at scales 1/1.5, every zone transition, rail/result scrolling, delayed category entry, caret/focus visibility after pointer input, typing, inline forms, Escape, Enter/Space toggle RPCs and matching logo/keyboard state. No golden updates were needed.
