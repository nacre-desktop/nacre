# N0410 — v0.1.0 cut preparation

Prepare the release and Arch packaging pipeline to accept the owner-approved
`v0.1.0` public preview when `VERSION` is changed later. This unit does not
change `VERSION`, write release notes, publish, or create tags/releases.

- Arch package versions omit snapshot suffixes for non-dev versions; dev
  versions keep their revision and commit suffix. Pacman ordering must place a
  dev snapshot before the corresponding public version.
- `release.yml` accepts `v0.x.y` and `v0.x.y-dev.N`. Dev releases retain their
  prerelease behavior; public releases are normal latest releases with the
  matching `CHANGELOG.md` section.
- Immutable Arch download releases use `arch-<version>` for public versions
  and retain `arch-dev-<version>` for development versions. The signed pacman
  repository remains at its existing development-channel URL.
- No temporary duplicate implementations or fixtures are introduced.

Acceptance: focused recipe/repository tests; `vercmp` confirms dev sorts before
public; ruff, compositor boundary, and available actionlint checks pass. No live
workflow run.
