# N0236 Bead pin bump to a6fbc10f

Moves every Bead pin from `5c0e3136` to `a6fbc10f44705a4ce651aed72bda9e19df9d752f` (Bead main head, hosted CI green) in one commit: nacre-shell `bead`, `bead-test`, `bead-wallpaper` and `bead-widgets`, nacre-helper `bead-services`, and `BEAD_REVISION` in `tools/check_product_shell.py`. `cargo update` touched only the 11 Bead packages, and Cargo.lock resolves one Bead revision.

## What the pin brings

- B0245 2a (write() syscall fix) and 2b (warm panels, opt-in; `warm_source_budget` stays 0, so no behaviour change; N0231 adds the adapter).
- B0249 niri and Hyprland compositor adapters. B0250 folder-app work (popup panels). B0256 drops the dead vendored fontconfig and the `vello`/`gpu` feature aliases (Nacre's own features of those names only forward to `wgpu`/`native-gl`). B0257 deletes unused facade sources and notification start wrappers.
- B0251: the clock runs on its own worker, so `Config { bus: false }` keeps the clock.
- B0255: hover and focus colour patching in the materialized cache.
- B0232 2b: the GraphCanvas GPU path (wgpu feature). Not adopted here; N0217 adopts it.
- B0258 removes `bead::host::empty_scene`, `local_range_feedback` and `Session::asset_snapshot`, and a6fbc10f drops the per-minute `CLOCK_TICK` stderr line. Nacre uses none of them.
- Text widths are now rounded up to whole pixels (`frontend.rs` `measured_width.ceil()`).

## What changed in Nacre

- `desktop::start_services(bus)`. The Widgets app's two `Desktop`s (warm runtime and window factory) start with `bus: false`. They only need the clock; their status stores come from daemon topics through `with_widget_app` → `bar_daemon`. That removes one system-bus thread from each of them, along with its NetworkManager, UPower and BlueZ reads and its StatusNotifierHost client.
- The bar keeps `bus: true`. Wallpaper motion (`wallpaper_motion.rs`) reads `session.locked`, `session.sleeping` and `battery.on_battery` from the bar's `Desktop`, and those come only from the bus lane. The daemon publishes `battery.on_battery`, but not lock or sleep (spec 0227 gap P1). With `bus: false` the motion wallpaper would keep decoding while the session is locked or asleep. Follow-up once P1 lands: read lock, sleep and on-battery from daemon topics, then set `bus: false` for the bar too.
- No API fixes were needed. No golden changed: the whole nacre-shell binary passed against the existing goldens, and no diff artifacts were written.
