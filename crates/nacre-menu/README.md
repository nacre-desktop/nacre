# Launcher engine

GPL-3.0-only launcher ranking, providers, desktop-entry parsing and calculator.
The daemon hosts the engine; Bead owns its UI.

Historical capture methods and immutable fixture provenance are recorded in
[the reference record](../../docs/research/n0156-reference/launcher-reference.md).
Desktop-entry adaptation authors and licenses are retained in
[the source notice](../../docs/research/launcher-engine-notice.md).
