Commissioner, SIL OFL 1.1 (Commissioner-OFL.txt), version 1.001. The name Commissioner is not a Reserved Font Name.
Source: https://github.com/google/fonts/tree/main/ofl/commissioner (Commissioner[FLAR,VOLM,slnt,wght].ttf, sha256 db01279a6eb8676ee62675a4d7e5edbfe5f08fbc109358e2f49760b70c0447d3).
Both files are fonttools instances (varLib.instancer) of that variable font with slnt pinned to 0 and wght kept variable (100-900):
- Commissioner.ttf: FLAR 0, VOLM 0, family "Commissioner" (the interface face).
- Commissioner-Display.ttf: FLAR 100, VOLM 100, family "Commissioner Display" (name table renamed; for display sizes).
The shell writes them to $XDG_DATA_HOME/nacre/fonts/ (~/.local/share/nacre/fonts/) when missing and registers them with Fontconfig for its own process only.
