# Nacre desktop helpers

These tools support Settings, wallpaper/colors, capture, optional applications and
managed updates. Use the normal Nacre interface or install.sh rather than copying
individual helpers into a live installation. User configuration, accounts and
wallpaper data stay outside these source files. See [installation](../../docs/installation.md)
and [recovery](../../docs/recovery.md). Nacre-owned source is GPL-3.0-only.
