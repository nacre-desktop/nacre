# Nacre desktop shell

The native shell provides the bar/frame, universal launcher, controls,
notifications and static/animated wallpapers. Settings, Colors and Welcome use
separate application windows. Install/update through the repository's install.sh;
source and user preferences are separate. See the main README and user guides.

Nacre-owned implementation: GPL-3.0-only. Qt/Quickshell are installed system
dependencies with their own licenses; no recovery/vendor implementation is bundled.
