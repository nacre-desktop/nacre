# Private knowledge index

Start with `nacre-brain pack WORLD|AREA`, then the relevant wiki/ page (curated
current truth) and its linked evidence in the dated topic folders. raw/ holds
attributed source extracts, checkpoints/ task handoffs, archive/ retired notes.
This index is regenerated by `nacre-brain-maintain consolidate`.

Read AGENTS.md for the shared policy. Run `nacre-brain-maintain check` after
substantial updates. Keep this vault and its backups out of public Git.
